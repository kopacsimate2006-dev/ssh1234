# III. Felhőszolgáltatás telepítése és beállítása – részletes lépésről lépésre útmutató

A feladat célja, hogy az Azure-ban létrehozz egy Windows és egy Linux virtuális gépet, majd különböző szolgáltatásokat konfigurálj rajtuk.

---

# 2. Windows virtuális gép létrehozása (SzisziVM)

## Virtuális gép létrehozása

1. A bal felső sarokban kattints:

   * „Create a resource”
   * vagy „Erőforrás létrehozása”

2. Válaszd:

   * „Virtual Machine”

3. Resource Group:

   * Kattints: „Create new”
   * Név: `vizsgazo`

4. Virtual machine name:

   * `SzisziVM`

5. Region:

   * válassz közeli régiót pl. West Europe

6. Image:

   * „Windows Server 2022 Datacenter”

7. Size:

   * hagyd alapértelmezetten vagy válassz kisebb méretet


# 3. Adminisztrátor adatok megadása

## Administrator account

1. Username:
   `szisziuser1`

2. Password:
   `Sziszi*2026!`

3. Confirm password:
   ugyanaz



# 4. Lemez beállítása

1. Menj a „Disks” részre.
2. Ellenőrizd, hogy:

   * OS Disk Size = `130 GB`

Ha nem 130 GB:

* kattints a „Change size” vagy „Create and attach a new disk” részre
* állítsd 130 GB-ra.


# 5. Hálózat beállítása

## Virtual Network létrehozása

1. Networking fül.
2. Virtual Network:

   * „Create new”
3. Név:
   `W2022NY2k`

## Address space

Állítsd be:

* `20.5.1.0/24`


# 6. Portok beállítása

## Inbound ports

Engedélyezd:

* RDP (3389)
* HTTP (80)

### Fontos:

Az RDP csak IPv4-re legyen engedélyezve.

# 8. Csatlakozás a Windows szerverhez

1. Nyisd meg a létrehozott virtuális gépet.

2. Kattints:

   * „Connect”
   * „RDP”

3. Töltsd le az RDP fájlt.

4. Nyisd meg.

5. Jelentkezz be:

Felhasználó:
`szisziuser1`

Jelszó:
`Sziszi*2026!`

# 9. Active Directory szolgáltatás telepítése

## Server Manager használata

1. Nyisd meg:

   * Server Manager

2. Kattints:

   * „Add roles and features”

3. Next → Next.

4. Válaszd ki a szervert.

5. Pipáld ki:

   * „Active Directory Domain Services”

6. Add Features.

7. Next → Install.

8. Telepítés után kattints:

   * „Promote this server to a domain controller”

---

# 10. Tartomány létrehozása

1. Válaszd:

   * „Add a new forest”

2. Root domain name:

   * `info26.local`

3. DSRM Password:

   * `Sziszi2026`

4. Next → Next → Install.

5. A gép újraindul.

# 11. IIS webszerver telepítése

# 12. Weboldal létrehozása

## HTML fájl létrehozása

1. Nyisd meg:
   `C:\inetpub\wwwroot`

2. Töröld a régi index fájlt, ha van.

3. Hozz létre új fájlt:
   `index.html`

4. Tartalma például:

```html
<html>
<head>
<title>Vizsga</title>
</head>
<body>
<h1>Kiss Béla</h1>
</body>
</html>
```

5. Mentsd el.

---

# 13. Weboldal tesztelése

2. Írd be:


3. Ha megjelenik a neved:

   * sikeres.

4. Készíts képernyőképet.

5. Mentsd:
