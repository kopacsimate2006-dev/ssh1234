14. Képernyőkép

Készíts screenshotot:

running-config
ping sikeres
OSPF
DHCP működés

Mentés:

Hálózat1_sajátnév
acl kitöltésnél melyik eszközön kell

Az ACL-t a feladat szerint a Sziszi_A routeren kell beállítani.

A dokumentumban ez szerepel:

„A Sziszi_A routeren állítson be alapértelmezett útvonalat (gi0/0/1) és vegyen fel ACL mondatot…”

Pontosan hova kell írni?

A CLI-ben a Sziszi_A routeren:

enable
configure terminal
ACL létrehozása
access-list 101 deny tcp any any eq 80
access-list 101 permit ip any any

VAGY ha hostname alapú tiltást akarnak:

ip host badacsony 1.1.1.1

de Packet Tracerben általában IP alapú ACL működik biztosan.

ACL alkalmazása

A feladat szerint a kimenő internetes interfész:

g0/0/1

Ezért:

interface g0/0/1
ip access-group 101 out
Mit csinál ez?
Tiltja a HTTP (80-as port) forgalmat
Minden más forgalmat enged
Vizsgán biztos működő ACL

Ezt érdemes használni:

access-list 101 deny tcp any any eq 80
access-list 101 permit ip any any

alkalmazás:

interface g0/0/1
ip access-group 101 out
